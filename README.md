# General Python Projects

A collection of Python practice programs, small games, calculators, and
data/AI-themed experiments.

## Projects

- `Artificial_Intelligence_Assistant.py` — a small command-line assistant.
- `Automated_numerical_brain.py` — numerical and math practice.
- `business_data_security_pipeline.py` — a business-data security pipeline exercise.
- `Calculator (Beginner).py` — a beginner calculator.
- `Calculator_AutomatedBot.py` — a calculator with automated input handling.
- `dice_game.py` — a simple dice game.
- `Digit Guessing Game.py` and `Number Guessing Game.py` — number-guessing games.
- `Local_AI_Data_Incident_Assistant.py` — a local data incident assistant.
- `simple_scientific_calculator.py` — a scientific calculator.

## Getting started

Use Python 3.10 or newer. The scripts are standalone; check each file for its
inputs and any project-specific requirements. For example:

```powershell
python .\dice_game.py
python .\simple_scientific_calculator.py
```

The empty `Mini-Project-Data Processor (AI Assistant).py` placeholder is
excluded from this repository until it contains a project.
